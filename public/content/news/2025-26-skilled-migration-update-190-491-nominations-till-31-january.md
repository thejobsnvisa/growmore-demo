## 2025–26 State Migration Update: 190 & 491 State Nominations Issued Till 31 January

The Department of Home Affairs has released updated nomination data for the 2025–26 program year that covers the period from 1 July 2025 to 31 January 2026.

So, whether you are planning for the Skilled Nominated (Subclass 190) or Skilled Work Regional (Subclass 491) visa, these numbers matter. They will help you in understanding which state is inviting more invitations, which occupations are getting priority, and how competitive the current migration rounds are.

Below is the official number of EOIs that have received state or territory nomination till the end of January.

## **Skilled Nominated Visa (Subclass 190) – Nomination Numbers**

Total nominations issued (1 July 2025 – 31 January 2026):

|     |     |
| --- | --- |
| **State / Territory** | **Nominations** |
| ACT | 345 |
| NSW | 886 |
| NT | 389 |
| QLD | 297 |
| SA | 448 |
| TAS | 491 |
| VIC | **1,136** |
| WA | 413 |

**What This Means**

- **Victoria (1,136)** is currently leading by a significant margin.

- **New South Wales (886)** remains highly competitive but active.

- **Tasmania (491)** and **South Australia (448)** are performing steadily.
