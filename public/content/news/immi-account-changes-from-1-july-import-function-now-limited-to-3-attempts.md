The Department of Home Affairs has announced a key update to the ImmiAccount system that will come into effect from 1 July. It introduces stricter controls on the use of the Import function.

This update is part of the Department’s focus on protecting applicant privacy, preventing misuse, and keeping visa application data more secure.

## What Is Changing? 

From 1 July, each Australia visa application can only be successfully imported into ImmiAccount a maximum of three times.

If anyone makes a fourth import attempt, the system will automatically block further imports of that application. Once it is blocked, the application cannot be imported again unless the restriction is manually reset by the Department.

**When this happens, users will see the following message:**

> "This application is not available for import. For more information, see Apply and manage your application."

## Why This Change Is Being Introduced

The Import function allows users to access visa applications using basic identifiers such as application ID or TRN, passport details, and date of birth.

**While this makes access convenient for legitimate users, it has also raised concerns around:**

### **1. Unauthorised access to applications**

### **2. Duplicate or repeated imports across multiple accounts**

### **3. Potential misuse of client information**

### **4. Increased risk of fraudulent activity**

To address these concerns, the Department is introducing a limit on import attempts to improve system integrity and strengthen the protection of applicant data.

## What Happens If an Application Is Blocked?

If an application reaches the three-import limit and gets blocked, Migration Agents and Legal Practitioners can request a reset through the ImmiAccount Technical Support Form. Once it is approved, the import counter will be reset, allowing up to three additional import attempts.

## Import vs Share vs Assign: Know the Difference

The Department has also highlighted that many Migration Agents and Legal Practitioners are relying heavily on the Import function, when better alternatives are available within Organisation ImmiAccounts.

**Here’s how the three functions differ:**

### **1. Import:** This function is used to add an application to an ImmiAccount by using details like application ID or TRN, date of birth, and passport details.

### **2. Share:** This function is used to invite another person to access and work on an application. This includes work related to attaching documents and updating details. In this, the original user can also retain full control of the application and choose whether to revoke access or remove the application from the shared user’s view at any time.

### **3. Assign:** This function is only available for Organisation ImmiAccounts, where a user can transfer an application within the organisation to another user or remove it from the original account.

## How Applicants and Agents Should Prepare for the New Import Limit

From 1 July, the Department of Home Affairs will limit the ImmiAccount Import function to three successful attempts per application. A fourth attempt will automatically block further imports unless reset by the Department. This update is mainly aimed at strengthening privacy, reducing misuse, and improving the security of visa application data across the system.
