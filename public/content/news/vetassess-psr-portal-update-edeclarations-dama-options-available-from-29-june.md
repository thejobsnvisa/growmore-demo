
From 29 June 2026, the Professional Skills Recognition (PSR) Application Portal managed by VETASSESS will undergo important functional upgrades. These updates are designed to improve application processing efficiency, accuracy, and overall user experience for skilled migration applicants.

This is particularly relevant for applicants using the [Designated Area Migration Agreement (DAMA) pathway](https://www.growmore.one/our-services/dama) or submitting skills assessment declarations, as the entire application experience is becoming more digital.

So, if you are planning to apply, renew, or request reassessment under the PSR system, here is a complete breakdown of what is changing.

## DAMA Renewals & Reassessments Now Available Directly in the Portal

One of the most significant upgrades is the ability to lodge DAMA renewal and reassessment [applications for Australia PR pathways](https://www.growmore.one/blogs/pr-pathway-in-australia-right-now-2026/) directly through the PSR portal. Previously, some DAMA-related processes involved external handling, but now everything will be integrated into a single online system.

**You will now be able to:**

* Submit DAMA renewal applications online through the PSR portal  
* Lodge DAMA reassessment applications directly without any offline processing  

Eligibility rules are still quite precise. For reassessments, you need to apply within 12 months of your original completed application. You can either stay in the same occupation or switch to a different one.

For renewal applications, you must already have a “suitable” outcome from a previous assessment. The application has to be submitted within 3 years of the completion date and must be for the same occupation as before.

## Introduction of Electronic Declarations (e-Declarations)

Another major update is the shift from manual signatures to fully electronic declarations in the PSR application process in Australia.

### **What is changing?**

**Applicants and authorised representatives will now be able to:**

* Sign application declarations digitally within the portal  
* Complete submission without printing or scanning documents  
* Use a fully online declaration process integrated into the application system  

**One important exception to keep in mind:**

If an applicant has already downloaded the declaration form, signed it, and uploaded it in an incomplete application, that submission will still be accepted under the current system without any issues.

## How These Updates Improve the Application Process

These updates are directed towards making Australia’s skills assessment and migration system fully digital.

### **Key benefits for Australia visa applicants include:**

* Faster and smoother application submission  
* Less paperwork and fewer manual errors  
* Better application tracking and transparency  
* Easier handling of DAMA applications  
* Built-in digital signing process  

This means the PSR portal makes applications simpler and more organised. Still, applicants need to stay careful because eligibility rules, deadlines, and documentation requirements are strictly imposed, even with the new system upgrades.
